# Abdulla Zahin — Field Log

A GitHub-backed interactive record of a Mechanical MEP Engineer with a Business Analyst mindset.

## What it contains

- A clickable career timeline
- A controlled field board for the current MEP assignment
- A filterable systems map across execution, analysis and engineering
- A visual field-note layer using selected, public-safe personal and site images

## Public-content boundary

This project publishes written case-study controls only. It intentionally excludes technical files, coordinated drawings, quantities, client/consultant correspondence, performance claims and other confidential project material.

## Run locally

Open `index.html` in a browser. No build tooling or dependencies are required.

## Deployment

Designed to deploy directly through GitHub Pages.
